# Tic-Tac-Toe Game

This is a simple and functional classic Tic-Tac-Toe game built with HTML, CSS, and JavaScript. 

## Project Structure

```
tic-tac-toe
├── src
│   ├── index.html       # HTML structure for the game
│   ├── styles
│   │   └── style.css    # CSS styles for the game
│   └── scripts
│       └── app.js       # JavaScript code for game logic
└── README.md            # Documentation for the project
```

## How to Play

1. Open `src/index.html` in your web browser.
2. The game board consists of a 3x3 grid.
3. Players take turns clicking on the empty squares to place their marks (X or O).
4. The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins the game.
5. If all squares are filled and no player has three in a row, the game ends in a draw.
6. You can refresh the page to reset the game and start over.
